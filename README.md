# ReelForge AI
### AI-Powered Viral Reel Script Generator

Generate complete viral reel packages instantly. Enter a topic, choose niche, tone, duration and language.

## Features
- Hook + Full Script with timestamps
- Shot-by-shot Storyboard
- Instagram & YouTube Captions
- 30 Trending Hashtags
- Music Mood per scene
- CapCut Editing Tips
- Thumbnail Idea
- Best Posting Time
- Viral Score 0-100

## Tech Stack
- Frontend: React.js
- Backend: Python Flask
- AI: Groq API (Llama 3.3 70B)
