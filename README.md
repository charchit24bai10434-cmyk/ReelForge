# ReelForge AI
### AI-Powered Viral Reel Script Generator

ReelForge AI generates complete viral reel packages in seconds using AI. Enter a topic, choose your niche, tone, duration and language — get a full script instantly.

## Features
- AI-generated Hook, Full Script with timestamps
- Shot-by-shot Storyboard
- Platform-specific Captions (Instagram & YouTube)
- 30 Trending Hashtags
- Music Mood per scene
- CapCut Editing Tips
- Thumbnail Idea
- Best Posting Time
- Viral Score (0-100)

## Tech Stack
- Frontend: React.js
- Backend: Python Flask
- AI: Groq API (Llama 3.3 70B)

## Setup

### Backend
cd backend
python3 -m venv venv
source venv/bin/activate
pip install flask flask-cors groq python-dotenv
Create .env file: GROQ_API_KEY=your_key_here
python app.py

### Frontend
cd frontend
npm install
npm start
